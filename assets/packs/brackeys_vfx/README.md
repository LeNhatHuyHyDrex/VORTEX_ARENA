# VFX in Godot
Project files for our video on VFX in Godot.

Check out the video on the [Brackeys YouTube Channel](http://youtube.com/brackeys).

## Brackeys VFX Bundle
All of these effects are made using the free assets from the [Brackeys VFX Bundle](https://brackeysgames.itch.io/brackeys-vfx-bundle). The assets are included in this repo.

## Brackeys Particle Controls
Properly preview particles in Godot with [Brackeys Particle Controls](https://github.com/Brackeys/brackeys-particle-controls). The plugin is *NOT* included in this repo.
